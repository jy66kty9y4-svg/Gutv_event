# Локальный макет ГУТВ

Изолированный статический макет главной страницы, «О студии», «Направлений», входа и регистрации. Содержимое взято с публичного сайта на 6 сентября 2026 года. Формы не отправляют данные; переключение страниц, темы и карусель работают локально.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 4175 --bind 127.0.0.1 --directory public/design-preview
```

Открыть http://127.0.0.1:4175. Остановка сервера — Ctrl+C.

Макет не использует приложение Next.js, его API, базу данных или переменные окружения. Для запуска не нужно устанавливать зависимости.

## Оформление

- Основные цвета: синий `#292e6b`, голубой `#d3edf6`, белый и чёрный — по присланному образцу.
- Три главных заголовка страниц: **Unbounded**, плавный геометрический гротеск с кириллицей. Остальные заголовки, навигация, кнопки и подписи: оригинальный **Epilepsy Sans**. Основной текст и поля: Arial.
- Логотип: оригинальное пользовательское JPEG. SVG-фильтр превращает яркость исходного рисунка в прозрачность и окрашивает его в синий для светлой темы или голубой для тёмной. Подложки нет, геометрия рисунка сохранена; файл не перерисован.
- Полосы: векторная декорация по мотивам референса. Пиксельные крестики и квадраты созданы CSS.
- Камера сохранена из существующего сайта с исходным альфа-каналом, без декоративной рамки, плашек или фона. Монохромное отображение применяется только стилем в макете.
- Светлая, тёмная и системная темы; настройки не затрагивают действующий сайт.

Лицензия и источник шрифта находятся в `fonts/`. Публичный снимок контента — `data.json`, изображения — `assets/`.
