# Epilepsy Sans

Original font by Kreative Software / Rebecca G. Bettencourt.

- Official family name: **Epilepsy Sans** (the requested “Epylepsy Sans”).
- Official catalog: https://www.kreativekorp.com/software/fonts/index.shtml
- Original archive: https://www.kreativekorp.com/swdownload/fonts/relaybm/epilepsy.zip
- Downloaded: 2026-09-06.
- The original TTF files are included unchanged, together with the archive's
  `FreeLicense.txt` (Kreative Software Relay Fonts Free Use License 1.2f).
- Both font files contain the complete Russian alphabet, including Ё/ё,
  verified directly against their Unicode cmap tables.

## CSS

```css
@font-face {
  font-family: 'Epilepsy Sans';
  src: url('/design-preview/fonts/EpilepsySans.ttf') format('truetype');
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}

@font-face {
  font-family: 'Epilepsy Sans';
  src: url('/design-preview/fonts/EpilepsySansBold.ttf') format('truetype');
  font-style: normal;
  font-weight: 700;
  font-display: swap;
}
```

The regular file's internal subfamily name is `Medium`; its full family name is
`Epilepsy Sans`. The bold file's full name is `Epilepsy Sans Bold`.
